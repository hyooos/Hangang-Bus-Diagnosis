## 레시피 개요

- 신규 도입된 대중교통 수단은 기존 수단보다 느리거나 배차가 길어 이용률이 낮고, 이것이 적자와 재정지원 논란으로 이어지는 경우가 많음. 이 레시피는 **"속도로는 기존 수단을 이길 수 없는 신규 교통수단이 누구에게, 어디서, 무엇을 고치면 쓰일 수 있는가"**를 공개 데이터만으로 진단하는 절차를 제시함
- 사례인 한강버스는 수심 제약으로 약 17km/h 이상 내기 어려워 통근 속도로는 지하철과 경쟁하기 어려움. 2025년 매출 54억원 중 여객 운송수입은 2억원에 그쳤고[S3], 시의회에서는 대중교통인지 관광수단인지 정체성부터 정해야 한다는 지적이 나옴[S6]. 반면 2026년 3월 이후 주말 탑승객 비중은 약 51%이고[S4], 선착장 인접역에는 휴일마다 한강을 찾는 수요가 모이고 있음
- 본 레시피는 운항 시간표와 교통카드·열차 시각표 데이터로 대기·환승·도보 부담을 **체감 통행시간(환승마찰지수, TFI)**으로 환산해 지하철과 비교하고, 유아차 동반 가족과 고령층 조건으로 선착장별 **수요 신호 × 접근성**을 진단함. 고령층은 경로당에서 출발하는 계단 없는 코스의 **걸음 수로 건강 목표(하루 6,000~8,000보) 달성 여부**를 평가함
- 그 결과 선박 추가 없이 가능한 처방(여의도 환승 동기화, 유아차 동반 시범, 건강 코스)과 투자가 필요한 처방(배차 단축, 급행)의 우선순위를 정하고, 주말 요금 인상 같은 정책 변화가 이용층별로 미치는 영향을 사전에 추정할 수 있음
- **시간표·선착장·인접역만 바꾸면 다른 신규 노선(수상교통, 경전철, 신규 버스노선 등)에 그대로 재사용할 수 있음**

## 분석모델 및 알고리즘

| 분석모델 | 알고리즘 |
| --- | --- |
| 진단 분석(일반화비용 기반 시나리오 시뮬레이션) | 환승마찰지수(TFI) + 탄력성 기반 수요 반응 모형 |

- 세 지표는 한 줄로 이어짐: 시간표 → **① 기대대기시간·환승대기(얼마나 기다리나)** → **② 환승마찰지수 TFI(기다림·환승·걷기를 합친 체감 통행시간)** → **③ 수요 반응(TFI가 바뀌면 이용이 얼마나 바뀌나)**. ①로 ②를 계산하고, ③은 ②의 변화를 이용 변화로 바꿔 해석함

#### ① 기대대기시간

- 시간표를 보지 않고 아무 때나 선착장에 온 승객이 평균적으로 기다리는 시간: `Σ(배차간격²) ÷ (2 × Σ배차간격) = (평균배차 ÷ 2) × (1 + 변동계수²)`
    - 배차가 일정하면 배차의 절반이지만, 불규칙하면 승객이 긴 배차 구간에 걸릴 확률이 높아 절반보다 길어짐(무작위 도착 대기 모형[R6]). `(1 + 변동계수²)`가 불규칙성 벌점
- 판단 기준: 미국 대중교통 서비스수준 지침(TCQSM)[R7]의 배차 등급 → 기대대기 5분 미만(배차 10분 미만) 시간표 없이 타는 수준 / 15분 이상(배차 30분 이상) 시간표에 맞춰야 하는 수준 / 30분 이상(배차 60분 이상) 최하 등급
- 여의도 환승대기 = 여의도 도착 후 최소 환승 3분이 지난 첫 출발편까지의 시간. 기준선은 동기화 이상값 3~5분, 두 노선이 서로 무관하게 운항할 때의 기대값(연결 노선 배차의 절반, 60분 배차면 약 30분). 이보다 크면 시간표가 오히려 엇갈려 있다는 뜻

#### ② 환승마찰지수(TFI)

- `TFI = 차내(배 위) 시간 + 1.8 × (첫 대기 + 환승대기) + 10 × 환승횟수 + 도보부담(외부 보행 100m당 2분)`
    - 모든 부담을 "앉아서 타고 가는 시간 몇 분과 같은가"로 환산한 체감 통행시간(분). 기다리는 1분은 타고 가는 1분보다 1.7~2.0배 힘들고[R3], 갈아타기 한 번은 10~15분만큼의 부담이라는[R4] 국내 연구 가중치를 사용함. 지하철 환승 통로 도보는 1분 = 1.6분(외부 보행 가중과 같은 비율)
- 판단 기준(레시피 기준선)
    - **지하철 대비 비율**(같은 출발역·도착역): 1.0 이하 경쟁 가능 / 1.0~1.5 여가·쾌적성 수요만 / 1.5 이상 통근 대체 어려움
    - **마찰 비중** `(TFI − 차내시간) ÷ TFI`: 30% 이상이면 속도보다 시간표·환승 개선 효과가 큼
- 유아차·고령층 TFI는 계단 구간을 엘리베이터·경사로 우회 경로로 바꾸고(OSM `highway=steps` 제외), 고령층은 보행속도를 1.2m/s → 1.0m/s로 낮춰 다시 계산함

#### ③ 수요 반응

- `새 수요 ÷ 현재 수요 = (새 TFI ÷ 현재 TFI)^ε`: "체감 통행시간이 1% 늘면 이용이 ε% 변한다"는 고정탄력성 수요함수. 변화가 커도 음수 수요 같은 비현실적 값이 나오지 않아 영국 교통연구소 수요 지침[R2]의 표준 형태임
- 해외 연구값이라 ε를 −0.3/−0.5/−0.7로 바꿔 범위로 제시하고, 결과는 이용객 수 예측이 아니라 **처방 간 크기 비교**에 사용함
- 판단 기준: 보수값(ε=−0.3)에서도 +10% 이상이면 "효과 확실", −0.5에서만 +10% 이상이면 "시범 후 확인", 세 값 모두 ±5% 이내면 "미미", 음수면 "역효과"
- 요금에 적용할 때 |ε| < 1이면 요금을 올려도 운임수입은 늘지만 승객은 줄어든다는 뜻으로 해석함

**데이터 변수 가이드라인**

- 타겟변수 ① **이용층별 체감 통행시간(TFI, 분)**: 데이터셋 ①로 선착장·방향별 기대대기와 여의도 환승대기를 구하고 배 위 시간·도보와 가중합. 데이터셋 ④로 같은 출발역·도착역의 지하철 TFI를 같은 식으로 구해 비율 산출
- 타겟변수 ② **휴일 쏠림 지수(HCI)**: 데이터셋 ②에서 인접역의 (휴일 평균 하차 ÷ 평일 평균 하차)를 서울 전체의 같은 값으로 나눔. 1보다 크면 서울 평균보다 휴일에 사람이 더 모이는 역
- 타겟변수 ③ **평일 낮 고령층 집중도**: 데이터셋 ③에서 인접역의 평일 10~17시 노인 하차 ÷ 평일 전일 노인 하차를, 관할역 전체 평균으로 나눔
- 타겟변수 ④ **건강 코스 걸음 수**: 경로당 → 선착장(계단 없는 경로) + 도착 선착장 → 역 거리를 보폭(0.65m, 0.6~0.7m 민감도)으로 나누고, 8,000보까지 필요한 공원 산책 거리를 산출

### 5. 시나리오 시뮬레이션·지하철 비교

- **한강버스 (`scenarios.py`)**: 배차(60/30/15분), 여의도 동기화, 격편 급행을 조합해 하루 시간표를 만들고, 11:00~18:40에 1분 간격으로 도착하는 가상 승객이 TFI가 가장 작은 배 조합을 고른다고 보고 평균을 냄. 동기화하지 않는 시나리오는 두 노선 출발 시각차를 0~(배차−1)분으로 바꿔 평균. 급행은 서울시 원계획(일반 75분·급행 54분, 정차 4곳 생략)에서 역산한 정차 1회당 5.25분 절감으로 여의도→잠실 85분 → 69분. 필요 선박 = 올림(왕복 운항시간 ÷ 배차), 서측 97분·동측 180분
- **지하철 (`subway_tfi.py`)**: 데이터셋 ④의 평일 시각표로 열차별 연결(connection)을 만들고 Connection Scan 알고리즘으로 출발역 도착 시각(11:00~18:40, 5분 간격)마다 가장 빨리 도착하는 경로를 찾음. 환승 통로 도보는 데이터 [D5]의 중앙값(없으면 4분)
- **비교 (`compare_subway.py`)**: 한강버스는 역 → 선착장 도보 + 배 + 선착장 → 역 도보까지 포함한 역→역 TFI로 계산해 지하철 TFI와 나눔

```python
def best(t, legs, w=1.8, pen=10, min_tr=3):             # 한강버스: 체감비용 최소 배 조합
    out = None
    for d1, a1 in legs[0]:
        if d1 < t: continue
        for d2, a2 in legs[1]:
            if d2 < a1 + min_tr: continue
            c = w * ((d1 - t) + (d2 - a1)) + (a1 - d1) + (a2 - d2) + pen
            out = c if out is None else min(out, c)
    return out

demand_change = lambda new, base, eps: (new / base) ** eps - 1
ships = lambda hw: -(-97 // hw) - (-180 // hw)
```

## 예상성과

- 선박 추가 없이 현재 편성의 출발 시각만 조정(여의도 동기화)해도 장거리 이동의 체감 통행시간을 약 18% 줄일 수 있고, 보유 선박 안(30분 배차, 10척)에서 장거리 26%·생활권 60% 단축이 가능함을 보여 운영 개선의 우선순위를 정할 수 있음
- 지하철 대비 체감시간 비율로 "통근 대체는 어렵고(1.6~4.9배) 짧은 생활권 구간만 배차 개선 시 여가 수요권(1.3배)에 들어온다"는 점을 수치로 제시해, 한강버스의 정체성 논의(대중교통 vs 관광)에 이용층별 근거를 제공할 수 있음
- 2년 연속 같은 순위로 휴일 수요가 모이는 선착장(뚝섬·여의도)과 수요는 높지만 접근이 어려운 선착장(잠실·압구정)을 구분해 유아차 동반 시범과 접근 경로 개선 대상을 근거 있게 정할 수 있고, 주말 요금 변화가 가족 이용과 부담에 미치는 영향을 공청회 전에 추정할 수 있음
- 경로당 위치에서 출발하는 계단 없는 건강 코스를 설계해 평일 낮 빈 좌석과 고령층 걷기 수요를 연결할 수 있으며, 공개 데이터만 쓰므로 다른 신규 교통수단의 이용 저조 진단에 그대로 재사용할 수 있음

## 분석결과 활용방안

- 운영사·미래한강본부 실무자 대시보드로 구현해 배차·동기화·급행·요금을 조정하면 이용층별 체감 통행시간, 지하철 대비 비율, 예상 이용 변화, 필요 선박 수를 즉시 확인할 수 있음
- 선착장마다 일반·유아차·고령층 도보 부담, 엘리베이터, 휴일 쏠림, 평일 낮 고령층 이동을 한 장에 담은 "선착장 진단 카드"를 만들어 시범사업 대상 선정과 나들목 개선 예산 배분에 활용할 수 있음
- 경로당 출발 건강 코스를 손목닥터9988 걷기 미션과 연계하고 참여 경로당과 비교군을 두어, 포인트 사업이 실제 외출·걸음을 늘리는지 검증하는 도구로 활용할 수 있음
- 선착장×시간대×요일 이용 집계를 확보하면 통근(평일 07~10·17~20시), 고령층(평일 10~17시), 가족(주말·공휴일) 세그먼트별 이용량을 KPI로 모니터링할 수 있으며, 휴일 쏠림 정보는 선착장 주변 상권과 부대사업 배치에도 활용할 수 있음(여의도 선착장 반경 500m 생활인구 +20.9%, 음식점 카드매출 +15.5%[S5])

## 한계 및 가정

- 여의도 도착 시각은 직전 출발 + 공식 구간시간으로 추정했으며, 실제 운항 기록으로 보정이 필요함
- 정차 1회당 손실시간(5.25분)은 서울시 원계획 수치에서 역산한 값이고, 동기화 효과는 한 방향(마곡→잠실) 기준임
- 지하철 TFI는 가장 빨리 도착하는 경로 기준이며(한강버스는 체감비용 최소 경로), 서울숲역(수인분당선)은 시각표에 없어 비교에서 제외함
- 수요 탄력성은 해외 연구값이므로 처방 간 크기 비교에만 사용함
- OSM 보행 경로는 8곳 중 4곳에서 공식 도보거리와 30% 넘게 어긋나(나들목 연결 누락) 유아차 경로는 현장 확인 후 확정해야 함
- 반려견 등록 수는 자치구 단위(2022년)이고, 고령층 데이터는 2024년·서울교통공사 관할역 기준임
- 경로당 좌표가 있는 표준데이터는 서울 25개 구 중 12개 구만 제공되어, 코스는 강서구(마곡)·강남구(압구정) 출발만 계산함. 나머지 구는 서울시 경로당 목록(주소)을 지오코딩해 같은 절차로 확장함
- 걸음 수는 평균 보폭 가정값이며, 유아차·반려동물 동반 변경은 선박 안전 검토를 전제로 함
